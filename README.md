# Imkon

Сайт студии Imkon: сайты, Telegram-боты, автоматизация, склад и учёт, приложения.

Один файл `public/index.html`, без сборки. Языки: таджикский, русский, английский.

## Как поменять

- Telegram-ник: константа `TELEGRAM` в начале скрипта в `public/index.html`.
- Тексты: объект `I18N` (ключи `ru`, `tj`, `en`).

## Публикация

Cloudflare Workers собирает сайт из ветки `main` автоматически: каждый пуш публикуется сам.
Настройки в `wrangler.jsonc`, публикуется только папка `public/`.
