# Imkon

Сайт студии Imkon: сайты, Telegram-боты, автоматизация, склад и учёт, приложения.

Один файл `index.html`, без сборки. Языки: таджикский, русский, английский.

## Как поменять

- Telegram-ник: константа `TELEGRAM` в начале скрипта в `index.html`.
- Тексты: объект `I18N` (ключи `ru`, `tj`, `en`).

## Публикация

Подходит любой статический хостинг: Cloudflare Pages, GitHub Pages, Netlify.
Папка для публикации — корень репозитория, команда сборки не нужна.
